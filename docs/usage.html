🔊 GameVolumeHotkey首頁使用方式建置

使用方式

  1. 啟動程式，開啟設定視窗。
  2. 指派靜音、音量增加、音量減少的全域快捷鍵（可用錄製方式輸入）。
  3. 縮到系統匣；視窗沒有焦點時快捷鍵仍然有效。

預設快捷鍵

靜音／取消靜音Alt+Delete
音量增加Alt+Up
音量減少Alt+Down

每次調整的幅度為 5%。

設定與記錄

  • 設定存放於使用者的 AppData 目錄下的 config.json，沒有檔案時使用預設值。
  • 程式會在同一個 AppData 目錄的 logs 資料夾寫入記錄。
  • 開機自啟動寫入目前使用者的 Windows 啟動登錄（HKCU）。
僅支援 Windows 10 以上 · GitHub
