GameVolumeHotkey

輕量的 Windows 桌面工具：玩遊戲、工作或使用全螢幕程式時，用全域快捷鍵控制系統音量。以 C++ 與 Qt 6 開發。

使用方式自行建置

全域快捷鍵

靜音／取消靜音、音量增加、音量減少，視窗沒有焦點也能用。

即時系統音量

透過 Windows Core Audio（IAudioEndpointVolume）。

系統匣常駐

縮到系統匣背景執行。

開機自啟動

可選，於系統匣選單切換。

單一執行個體

避免重複開啟多個視窗。

設定自動儲存

快捷鍵與偏好儲存在 config.json。

僅支援 Windows 10 以上 · GitHub
